物仓的首个公开版本：离线管理物品照片、分类标签和库存数量，并随时导出库存清单。

### 功能

- 系统相机拍照 / 相册导入，支持命名、编辑、删除与照片更换。
- 分类和标签管理，按关键词、分类、多个标签及库存状态组合筛选。
- 直接输入数量或一键增减，设置低库存阈值，查看库存总览。
- 导出全部库存或当前筛选结果为中文 CSV，支持保存文件和系统分享。
- 库存使用本机 SQLite 持久保存，导入的照片保存在应用私有目录。

### 下载

- `WuCang-1.0.0-debug.apk`：可直接安装的 Android 测试版本，最低 Android 8.0（API 26）。
- `SHA256SUMS.txt`：APK 的 SHA-256 校验值。
- **Source code (zip)** / **Source code (tar.gz)**：GitHub 自动提供的本版本源码归档，包含 Gradle Wrapper、测试、界面截图及许可证。

APK 使用 Android Debug 证书签名。应用商店发布需另行配置正式签名。首次安装为空库存，不包含截图中的测试物品。

### 验证

功能代码在 Android API 37 模拟器上通过 21 项设备测试；测试清理调整后的 2 项界面用例也已单独复跑通过。实际跑通系统拍照、相册选择、分类标签、数量修改、检索筛选、CSV 保存与分享面板、强制停止后数据保留。发布前重新构建并加入许可证文件。

真实手机厂商相机兼容性和第三方接收方打开分享文件尚未逐一实测。CSV 不包含照片；卸载应用或清除应用数据会删除本地库存与照片。
